Mobile-friendly gym checkout with a Venmo handoff, manual staff verification,
discounts, transaction management, and monthly sales reporting.

== Installation ==

1. Upload and activate the plugin.
2. Open Settings > Gym Store and complete the setup fields.
3. Add [gym_venmo_checkout] to a WordPress page.
4. Enable Test Mode and test the full flow before production use.

== Important ==

This plugin does not use a Venmo merchant API and cannot independently verify
payment. Staff must verify each payment in Venmo before marking it received.
